# Markpad

A **minimal** Markdown editor built with _Electron_.

## Features

- Light & dark theme (toggle top-right, or `Cmd/Ctrl+T`)
- File browser in the left sidebar
- Formatting **toolbar** — no syntax memorisation needed
- Switch between `Code`, `Split` and `Preview`
